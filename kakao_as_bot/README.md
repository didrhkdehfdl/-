# 경기지사 A/S 단톡방 → 현장대응 엑셀 자동 정리

**「경기지사 A/S 단톡방」 하나만** 읽어서(다른 방은 읽지 않음) 1시간마다
`W:\6.O&M\` 폴더의 현장대응 엑셀 「2026년도 데이터」 시트에 반영합니다.

| 카톡 글 | 엑셀에서 하는 일 | 색 |
|---|---|---|
| `[접수]` 양식 | 맨 아래에 새 줄 추가 (C~N열) | 노란색 |
| `[처리]` 양식 | 연락처·고객명·발전소명으로 처리 안 된 접수 줄을 찾아 E, O~AI열 채움 | 연두색 |
| `[처리]` 인데 이미 처리된 건 | 접수 정보를 복사한 새 줄 추가 (추가 방문) | 연두색 |
| 양식 없이 올린 연락처 공유(이름:/휴대전화:/집:) | 접수로 보고 새 줄 추가 | 노란색 |

카톡방에 올릴 양식은 **`카톡방_양식.txt`** 를 단톡방 공지로 올려 두세요.
No.(B열)·자재비합계(Z열) 수식은 자동으로 채워집니다.

## 설치 (처음 한 번)

1. Python 설치: https://www.python.org/downloads/ (설치 화면에서 **Add python.exe to PATH** 체크)
2. 이 폴더를 PC에 복사 (예: `C:\kakao_as_bot`)
3. `1_설치.bat` 더블클릭
4. `config.json` 을 메모장으로 열어 수정
   - `room_name`: 카톡방 이름 (기본값 `경기지사 A/S 단톡방`, 카톡방 창 제목과 글자 하나까지 똑같이)
   - `excel_folder`: 기본값 `W:\\6.O&M` (역슬래시는 두 번)
   - `excel_file`: 엑셀 파일 이름 (현재 `독립채산제(AS,타부서지원)_TEST.xlsx`, 시험이 끝나면 실제 파일 이름으로 바꾸세요). 비워 두면 폴더에서 이름에 '현장대응'/'AS' 가 들어간 파일을 찾고, 여러 개면 오류로 알려 줍니다.
   - `defaults`, `sender_to_requester`: 요청부서·요청자 기본값
5. (선택) 자유 형식 글도 정리하려면 Claude API 키를 환경변수 `ANTHROPIC_API_KEY` 로 등록
   - 키가 없으면 `이름:/휴대전화:/집:` 형식 글만 정리합니다.
6. 시험 실행: `run.bat` 더블클릭 → 첫 실행은 기존 글을 "처리됨"으로 표시만 하고,
   다음 실행부터 새 글을 정리합니다. 결과는 `run.log` 에 기록됩니다.
7. `2_자동실행_등록.bat` 더블클릭 → 1시간마다 자동 실행

## 주의

- PC가 켜져 있고, 카카오톡에 로그인되어 있어야 합니다. 해당 채팅방 창을 열어 두면 가장 안정적입니다(최소화 가능).
- 화면 잠금 상태에서는 카톡 복사가 안 될 수 있습니다.
- 사진 속 내용(예: 인버터 오류 코드)은 읽지 못하고 `사진 첨부(카톡 확인)` 으로 표시됩니다.
- 같은 연락처 + 같은 접수일자는 중복으로 보고 건너뜁니다(답장으로 다시 올린 글 등).
- 이 PC에서 엑셀이 열려 있으면 그 창에 바로 반영되고 저장됩니다.
- 다른 사람이 W: 드라이브의 파일을 열고 있어서 읽기 전용이면 이번엔 건너뛰고, 다음 시간에 다시 시도합니다(글은 놓치지 않음).
- 엑셀 머리글(C3=A/S, D3=접수일자, O3=조치 내역, AA3=처리자 등)이 바뀌면 쓰지 않고 오류로 알려 줍니다.

## 카톡 직접 읽기가 안 될 때

카톡방 메뉴 → 대화 내용 → 대화 내보내기로 txt 를 저장한 뒤:

```
python run.py --file 저장한파일.txt --dry-run   (엑셀에 쓰지 않고 결과만 확인)
python run.py --file 저장한파일.txt             (엑셀에 추가)
```
